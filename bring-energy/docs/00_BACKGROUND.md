# 00. 개발 배경 — BRING 전기요금 절감 진단 SaaS

> 이 문서는 **왜** 이 제품을 만드는가에 대한 답입니다.
> **어떻게** 만드는가는 [`01_BRING_SPEC_v1.0.md`](./01_BRING_SPEC_v1.0.md)에 정리되어 있습니다.

---

## 1. 제품 한 줄 정의

> **고지서 사진 1장으로 시작하는, 한전 요금 고시 기반 자동 절감 진단 SaaS.**

전기 고지서 1장(또는 수치 직접 입력)으로 AI가 절감 가능 금액을 즉시 계산하고,
선택적으로 기기 사진을 추가하면 더 정밀한 분석 리포트를 자동 생성한다.
유료 리포트 발행 후, 자연스럽게 현장 CT센서 컨설팅으로 업셀하는 구조.

---

## 2. 사업적 출발점

### 2-1. 브링 에너지 사업의 큰 그림

브링엔지니어링은 CT센서 기반 에너지 모니터링·자동제어 사업을 추진 중이며, 상지대 캠퍼스를
테스트베드로 확보한 상태. 그러나 **CT센서 설치·납품 모델은 영업 사이클이 길고 현장 인력이 필요**하기
때문에, 단기 현금흐름과 레퍼런스 확보를 동시에 달성할 새로운 진입점이 필요했다.

### 2-2. 왜 "고지서 1장 → 자동 진단"인가

- **결재 허들이 낮음**: 공사 없이 PDF 리포트 한 장이라 고객 입장에서 부담 없음
- **원격·자동화 가능**: 대표 1인이 운영해도 스케일 가능
- **현장 컨설팅 업셀의 미끼**: 리포트가 신뢰감을 주면 자연스럽게 100만원대 현장 컨설팅으로 연결
- **데이터 자산화**: 진단 누적 → 업종별 벤치마크 DB → 향후 ESCO·ESG 컨설팅의 기반

핵심은 이것: **"이 회사 진짜 전문가구나"를 PDF 한 장으로 느끼게 만드는 것.**
신뢰가 없으면 3만원짜리 PDF가 끝이고, 신뢰가 있으면 100만원짜리 컨설팅으로 자연 연결된다.

## 3. 타깃 고객 & 진짜 니즈

### 3-1. 타깃 페르소나

- **월 전기요금 30만원 이상**이 나오는 사업장
- **소상공인 / 자영업자 / 소규모 공장주 / 노후 건물 관리자**
- 현재 전기요금에 대해 "왜 이렇게 많이 나오지?" 의문이 있지만, 어디부터 손대야 할지 모르는 사람
- 이미 효율화가 잘 된 신축 건물·대형 시설은 타깃 아님

### 3-2. 고객군별 표면 니즈 vs 진짜 니즈

| 고객군 | 표면적 니즈 | 진짜 니즈 |
|--------|-------------|-----------|
| 대학교 | 전기요금 절감 | 예산 절감 실적 → 총무처 KPI |
| 공공기관·지자체 | 에너지 효율화 | ESG 공시·탄소중립 이행 실적 |
| 중소 제조공장 | 전기요금 절감 | 원가 절감 → 영업이익 개선 |
| 대학병원 | 운영비 절감 | 24시간 무중단 + 비용 절감 동시 |
| 건물주·상업시설 | 관리비 절감 | 공실률 낮추기 위한 관리비 경쟁력 |

**시사점**: 메시지를 "전기요금 절감"이 아니라 **고객별 진짜 니즈의 언어**로 번역해서 전달해야 한다.

### 3-3. 절감이 잘 되는 / 안 되는 건물 조건

#### ✅ 절감 효과 높은 상황
- 낭비 전력이 많은 노후 건물 (강의동·관공서·구형 공장)
- 야간·주말 공실이 많은 시설
- 현재 수동으로 관리하거나 모니터링이 없는 곳
- 고압 계약으로 절감 단가가 큰 곳

#### ❌ 절감 효과 낮은 상황
- 이미 에너지 효율 설비로 잘 갖춰진 건물
- 24시간 풀가동 시설 (병원 수술실, 서버실)
- 사람이 없는 시간대가 거의 없는 시설
- 입주자가 많아 제어 권한이 분산된 건물

→ **타깃을 좁히는 것이 실패 확률을 낮추는 가장 현실적인 전략.**
모든 건물에 팔려 하지 말고, 우리 제품이 잘 먹히는 곳을 정의하는 것이 먼저다.

## 4. 상품 깔때기 (Funnel)

```
  ┌──────────────────────────────────────────┐
  │  1. 무료 간이 진단 (유입용)               │  ← 고지서 수치만 입력
  │     "연간 약 OOO만원 절감 가능"           │
  └────────────────┬─────────────────────────┘
                   │
                   ▼
  ┌──────────────────────────────────────────┐
  │  2. 유료 정밀 리포트 ₩39,000             │  ← PDF 4페이지 + 한전 약관 근거
  │     체감 가치 = 수십만원                  │
  └────────────────┬─────────────────────────┘
                   │
                   ▼
  ┌──────────────────────────────────────────┐
  │  3. 현장 CT센서 컨설팅 ₩100만원~          │  ← 2주 측정 + 정밀 계획
  └────────────────┬─────────────────────────┘
                   │
                   ▼
  ┌──────────────────────────────────────────┐
  │  4. ESCO 성과공유 (장기)                 │  ← 절감액의 일정 % 지속 수취
  └──────────────────────────────────────────┘
```

각 단계의 핵심 KPI:
- 1→2 결제 전환율 (목표 15%+)
- 2→3 컨설팅 전환율 (목표 5%+)
- 3→4 ESCO 전환율 (목표 20%+)

## 5. 신뢰도 확보 원칙 ⭐ (제품의 핵심)

> 리포트가 "예측"이면 3만원도 아깝고, "계산"이면 30만원도 싸다.

### 5-1. 핵심 원칙
- **모든 숫자는 한전 고시 요금표 기준 시뮬레이션**이지 AI 추측이 아니다.
- 모든 절감액 옆에 **근거 조항(예: 한전 전기공급약관 제43조)** 과 **단가**를 명시한다.
- 계산 과정 자체가 보이는 구조 — 사칙연산만 사용 → 반박 불가.

### 5-2. 신뢰감을 만드는 3요소
1. **숫자의 정확성**: "예상이요" 가 아니라 "한전 요금 고시 기준 계산 시"라는 근거
2. **고객이 몰랐던 걸 알려줌**: "어, 이거 나도 몰랐는데?" 하는 인사이트
3. **시각화**: 숫자를 그래프로 보여줬을 때 체감이 완전히 다름

### 5-3. 리포트에 반드시 들어가야 하는 문장 구조 (예시)

> "귀사의 현재 계약전력은 OOkW이나, 최근 고지서 기준 실제 최대 사용전력은 OOkW로 확인됩니다.
> 한전 전기공급약관 제43조에 따라 계약전력 조정 신청 시 월 OO만원, 연간 OO만원의 기본요금 절감이
> 가능합니다. (산출 근거: 한전 일반용 저압 기본요금 단가 6,160원/kW 적용)"

이 한 문장이 리포트 전체의 신뢰도를 결정한다. **숫자 + 법적 근거 조항 + 계산 과정**이 전부 보이는 구조.

## 6. 한전 약관 기반 핵심 계산 3종 (요약)

상세 수식은 [`01_BRING_SPEC_v1.0.md`](./01_BRING_SPEC_v1.0.md) §3 참조.

### 계산 1 — 계약전력 최적화
- **근거**: 한전 전기공급약관 제43조
- **로직**: 실제 최대수요전력 × 1.1(안전마진) → 최적 계약전력 → 기본요금 차이
- **예시**: 50kW → 33kW 조정 시 월 약 105,000원, 연 약 126만원 절감

### 계산 2 — 계약종별 변경
- **근거**: 산업통상자원부 고시 제2024-1호
- **로직**: 일반용 저압 사용량이 임계치 초과 시 고압A 단가와 비교 → 월 차이 계산
- **주의**: 수전설비 공사비 ROI 계산 필수

### 계산 3 — 역률 개선
- **근거**: 한전 전기공급약관 제72조
- **로직**: 90% 미만 1%당 0.2% 할증, 95% 초과 1%당 0.2% 할인
- **주의**: 콘덴서 설치비 대비 ROI를 따져 권고 여부 결정

## 7. 고지서 한계와 보완책

### 7-1. 고지서로 가능한 것
- 계약전력 과잉 여부 (수학적 증명 가능)
- kWh당 단가 비교 (한전 공시 요금표 대비)
- 계약종별 변경 검토
- 업종 평균 대비 위치 (벤치마크 DB 구축 시)

### 7-2. 고지서로 불가능한 것
> 고지서는 **결과**만 있고, **언제·어디서·뭐가** 전기를 쓰는지는 없다.

월 300만원 전기요금이 나와도, 에어컨 때문인지·기계 공회전 때문인지·야간 미소등 때문인지는 알 수 없다.

### 7-3. 보완책: 선택적 기기 사진 업로드
사용자가 원할 경우 기기 라벨 사진을 업로드하면 Claude API가 정격소비전력을 추출하고,
**예상 소비량 vs 실제 청구액**의 차이로 "숨은 낭비전력"을 도출한다.

이 갭이 클수록 **현장 CT센서 컨설팅의 필요성**이 자연스럽게 증명된다.

## 8. 사업 확장 로드맵

```
STEP 1. 데이터 자산화 (즉시)
  - SaaS 운영 시작, 진단 리포트 누적
  - 절감 케이스 정량 문서화 → 모든 영업의 첫 번째 증거물

STEP 2. 복수 건물 확장 (3~6개월)
  - 상지대 캠퍼스 내 다른 건물로 확대 설치 제안
  - 다양한 건물 유형 데이터 확보 → 범용성 증명

STEP 3. 외부 기관 영업 (6~12개월)
  - 레퍼런스 들고 공공기관·지자체·대학병원 타깃
  - 계약 모델 선택: ESCO 성과공유 / SaaS 구독 / 데이터 라이선싱

STEP 4. 피지컬 월드 데이터 인프라 (1~2년)
  - 건물별 에너지 소비 패턴 DB 구축
  - 전력 컨설팅사·ESG 플랫폼·RE100 기업에 데이터 판매
```

## 부록 B — 용어 사전

| 용어 | 설명 |
|------|------|
| **계약전력 (kW)** | 한전과 계약한 최대 사용 가능 전력. 기본요금 산정의 기준. |
| **사용량 (kWh)** | 실제로 쓴 전력량. 기본요금이 아닌 전력량요금 산정의 기준. |
| **기본요금** | 계약전력에 단가를 곱한 금액. 사용량과 무관하게 매월 부과. |
| **전력량요금** | 실제 사용한 kWh × 단가. 시간대·계절·계약종별로 단가 다름. |
| **역률 (Power Factor)** | 유효전력 ÷ 피상전력. 90% 미만이면 한전이 기본요금을 할증. |
| **최대수요전력** | 15분 단위 평균 전력의 월 최댓값. 계약전력 적정성 판단의 핵심 지표. |
| **계약종별** | 일반용 / 산업용 / 교육용 / 주택용 등. 같은 사용량이라도 단가가 다름. |
| **부하율** | (평균 전력 ÷ 최대 전력) × 100. 낮을수록 전력 사용이 들쭉날쭉. |
| **CT센서** | 분전반에 설치해 회로별 실시간 전력을 측정하는 비접촉식 센서. |
| **ESCO** | Energy Service Company. 절감액의 일부를 수익으로 가져가는 사업 구조. |
| **TOU 요금제** | Time-of-Use. 시간대별로 단가가 다른 선택 요금제. 야간·주말 사용 비중이 크면 유리. |
